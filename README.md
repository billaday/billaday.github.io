# 廖晨聪个人主页

用于 GitHub Pages 的中英文静态个人主页，保留原始版式及五处最新文字修改。

## 发布

1. 登录 GitHub 账号 billaday。
2. 先检查是否已有 billaday.github.io 仓库；如果已有，请先检查内容，勿覆盖原网站。
3. 如没有，新建名为 billaday.github.io 的公开仓库。
4. 将本文件夹内的文件和 assets、en 文件夹上传到仓库根目录，确保 index.html 位于根目录。不要上传 ZIP 文件本身。
5. 打开仓库 Settings → Pages，Source 选择 Deploy from a branch，分支选择 main，目录选择 / (root)，保存。
6. 等待发布完成后访问 https://billaday.github.io/?lang=zh；英文地址为 https://billaday.github.io/en/。

## 修改文字

- 中文：index.html
- 英文：en/index.html
- 样式：styles.css
- 语言切换与菜单：script.js
- 图片：assets/

本包仅包含公开网页所需内容，不含原始申报书、职称材料、Sites 凭据或 Git 历史。GitHub 发布前需确认账号授权和仓库现有内容。
